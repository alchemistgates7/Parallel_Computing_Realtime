### 通信搭建
先建立物理链接，后建立逻辑链接。
物理链接-》网线或者路由器，逻辑链接-》知道对方的IP地址。
首先，IP地址是随机分配的，由交换机或者路由器分配。\
交换机只能在一个子网内部寻址，路由器可以从一个子网跨越到另一个子网。只有Public IP 才能让所有人访问，需要花钱买。\
在IPv4的协议下，IP地址有32位，拆成4*8bits。e.g 192.168.1.101
为了方便记忆，用host来代替ip地址。\
192.168.1.101/24 意为建立了一个192.168.1.1的局域网，前24位不变（192.168.1），后8位可以分配给254个主机，即子网掩码 255.255.255.0
